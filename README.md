# Nandan Gaikwad - Engineering & Design Portfolio

An interactive, performance-driven personal developer portfolio built with React 19, Vite, GSAP animations, and Lenis smooth scrolling.

---

## ⚡ Tech Stack & Architecture

- **Core Framework**: React 19, Vite
- **Routing**: React Router v7 (SPA with Netlify rewrite rules)
- **Animations & Interactivity**: GSAP (ScrollTrigger), Lenis Smooth Scroll
- **Icons**: Lucide React
- **Styling**: Modern responsive CSS with custom typography, dark aesthetic, and fluid micro-interactions
- **Deployment**: Netlify & GitHub

---

## 🚀 Getting Started Locally

### Prerequisites

- Node.js (v18+ or v20+ recommended)
- npm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Nandangaikwad1710/portfolio-final.git

# Navigate into the project directory
cd portfolio-final

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 🛠️ Building for Production

```bash
npm run build
```

The optimized static assets will be output to the `dist/` folder. You can preview the production build locally with:

```bash
npm run preview
```

## 🌐 Deploying to Netlify

### Option 1: Automatic Deployment with GitHub (Recommended)

1. Push this repository to GitHub.
2. Go to [Netlify App](https://app.netlify.com/).
3. Click **"Add new site"** &rarr; **"Import an existing project"**.
4. Select **GitHub** and authorize access.
5. Choose your `portfolio-final` repository.
6. Netlify will automatically detect settings from `netlify.toml`:
   - **Build command**: `npm run build`
   - **Publish directory**: `dist`
7. Click **"Deploy site"**!

### Option 2: Drag & Drop (Netlify Drop)

1. Run `npm run build`.
2. Visit [app.netlify.com/drop](https://app.netlify.com/drop).
3. Drag the generated `dist` folder into the upload box.
